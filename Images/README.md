# Images

Carpeta para las ilustraciones de la wiki.

- Formatos admitidos: `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, `.avif`.
- Nombres sin espacios, acentos ni símbolos: `espada-cromatica.png`.
- Se referencian desde la ficha como `Images/espada-cromatica.png`.

Importante: la web es estática (GitHub Pages). Añadir un archivo a esta carpeta
no lo publica por sí solo: hay que hacer `git add`, `commit` y `push`.
